# Serverside Exercise – QA Test Coverage

This repository contains my solution for the Fullstack Java QA exercise.

## Test Coverage

The following types of tests were added based on the exercise requirements:

### Gherkin Scenarios
- High-level behavioral scenarios covering the data export functionality.
- Focus on user-visible behavior and acceptance criteria.

### End-to-End Test
- Validates the critical user workflow for exporting transaction data.
- Ensures data is correctly fetched and rendered before export.

### Unit Tests
- Covers key frontend logic related to data fetching and rendering.
- Focuses on predictable behavior and edge cases.

## Notes
- Tests were written to demonstrate testing approach and reasoning rather than exhaustive coverage.
- The project can be run locally using the existing setup from the exercise.
